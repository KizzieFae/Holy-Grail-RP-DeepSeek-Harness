# GitHub issue templates (governance notes)

GitHub requires issue forms under **`.github/ISSUE_TEMPLATE/`**; those files are not relocated.

## Ownership (from `governance/project-sync.toml`)

| File | Classification |
|------|------------------|
| `bug.md` | template_managed |
| `general-issue.md` | template_managed |
| `holy_grail_rp.yml` | project_owned |
| `config.yml` | project_owned |

## Contract pointers

- **Issue body / workflow §A–§K:** `governance/rp-app/issue-tracking-workflow.md` (canonical).
- **Holy Grail form copy:** `.github/ISSUE_TEMPLATE/holy_grail_rp.yml` references that governance path for §D–§I and related instructions.
