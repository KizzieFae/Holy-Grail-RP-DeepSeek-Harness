## 3. Governing-question answer

> **If Holy Grail were designed today from first principles, which RP turn components would we deliberately build again?**

**Answer:** Rebuild a **tiered A2 architecture**:

1. **Deterministic substrate** — Continuity authority, PVR/entitlement, retrieval/indexing, bounded projection, structural validation, audit/provenance, obligation routing.
2. **Primary RP cognition** — logically distinct **Character agency**, **Director turn responsibility**, **Narrator presentation**; physically coalescible on simple beats where authority boundaries remain inspectable.
3. **Persistent Plot/Scribe narrative cognition** — **retain the function**; default **async/off critical path**; topology and long-horizon value **unresolved** until a functioning generation → persistence → projection → consumption pathway is validated.
4. **Conditional support cognition** — orientation, decomposition, env grounding, semantic repair, retrieval mediation — **only on raised obligations**, not every turn.
5. **Do not rebuild** the A4 default synchronous stack: Storyteller preamble, post-commit Storyteller pressure, always-on Director/Narrator semantic QA, always-on env cognition, default Librarian mediation, ~26-kind simple-turn topology.

Historical necessity explains why A4 machinery exists; it does not establish that we would rebuild it today.

## 8. Recommended architecture family

**A2 — Primary RP + persistent Plot/Scribe + deterministic substrate**, with **obligation-driven escalation** and **tiered simple/complex/massive-knowledge paths**.

Confidence: **High** on direction; **medium** on exact tier triggers and physical coalescence boundaries; **low** on optimal Plot topology and long-horizon Plot value.

## 9. Updated A2 target topology

```
Player submit
  → Deterministic ingress (PVR triage, uniform gate, obligation router)
  → Entitlement + retrieval selection + bounded projection
  → [Conditional: decomposition, orientation, env obligation, retrieval mediation]
  → Director eligibility (deterministic) → Director decision [LLM or policy]
  → Character move(s) [LLM per entitled actor or batched with inspectable boundaries]
  → Deterministic validation (structural, spatial, entitlement, scenario)
  → [Conditional: semantic repair]
  → Host commit (Continuity authority)
  → Narrator presentation [LLM]
  → [Async: Plot/Scribe update → persist → project on next eligible turn]
  → Audit emission
```

**Default critical path:** deterministic gates + Director + Character + Narrator + validation. Everything else is obligation-triggered or async.

## 10. Simple-beat path

**Evidence:** G3-B F1 — A2 mean 4.59 vs lean A4 4.32 (Δ +0.27); 5 vs 28 round-sync LLM; 11K vs 74K input tokens.

**Path:** PVR uniform when eligible → skip preamble, orientation, semantic eval, env cognition, librarian → Director (if multi-actor or policy requires) → Character → Narrator → commit.

**Obligations that may escalate:** non-uniform player post, explicit env grounding obligation, entitlement conflict, validation failure.

---

## 11. Complex / multi-character path

**Evidence:** G3-C F2 — objective parity; A2 −0.14 blind mean at N=2 (qualified support); 6 vs 45 round-sync LLM; Director retained and consequential.

**Path:** Full Director actor selection → per-actor Character with isolated manifests → spatial/zone validation → optional conditional orientation only when knowledge package complexity exceeds deterministic projection.

**Known debt:** deictic/spatial claim extraction gap (Sample D) — deterministic validator + targeted repair, not full A4 stack restoration.

---

## 12. Massive-knowledge path

**Evidence:** G3-E — A2 4.754 vs lean A4 4.627 (Δ +0.127); narrative usefulness +0.286; 0 vs 20 Librarian; 82.6K vs 367.6K input tokens; K3 perfect both arms; K6 fails both arms.

**Path:** Indexed retrieval forensics → entitlement filter → ranked selection → **bounded projection** (current 8-record cap in harness) → Primary RP synthesis. Retrieval mediation **only** when deterministic path surfaces unresolved conflict, ambiguity, insufficiency, or multi-record synthesis Primary RP cannot resolve.

**Not claimed:** validation beyond 307-record single-beat corpus.

## 25. Post-#201 Long-Horizon Validation Reservation

**Current #201 evidence is insufficient** to determine the long-term value and optimal topology of persistent Plot/Scribe narrative cognition.

A future program (not numbered G3; not part of #201) must test **functioning** generation → persistence → **projection** → **consumption** → decision influence across:

- Many turns and multiple scenes
- Dormant/resurfacing threads
- Competing agendas and delayed consequences
- Evolving relationships and old commitments
- Foreshadowing/payoff
- Accumulated world information
- Increasing context/attention pressure

**Four turns (G3-D) is short-horizon/local-scene evidence only.**

This reservation does **not** delay or erase the current architecture conclusion. Plot function remains provisionally retained; sync-default and topology remain open.
