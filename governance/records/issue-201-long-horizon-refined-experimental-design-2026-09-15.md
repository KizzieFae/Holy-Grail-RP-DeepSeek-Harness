## 7. Refined hypotheses

| ID | Hypothesis |
|----|------------|
| **H0** | Primary RP + deterministic substrate + Continuity/retrieval suffice for high-quality **aged** RP without dedicated persistent narrative LLM cognition. |
| **H1** | Async Plot/Scribe adds consequential aged-story value **when** generation → persistence → projection → consumption → decision influence is proven. |

| **H4** | Persistent cognition value emerges only after a **minimum story-age threshold** (checkpoint divergence expected ≥T16). |
| **H5** | Persistent cognition cost per **activated consequential obligation** remains justified at medium horizon. |
| **H6** | Correctly **deferred** obligations (not yet activated) predict later consequential payoff better than unused persistent state. |
| **H7** | Seam failures (retrieval/projection/consumption) account for apparent persistent-agent failures unless proven otherwise. |

**Governance hypothesis (testable, not assumed):**

> Responsibilities currently distributed among Director, Storyteller, and Plot/Scribe may ultimately be better represented by a consolidated persistent narrative-intelligence agent — or by no dedicated agent, or partial consolidation.

## 10. Deferred-obligation lifecycle model

Persistent cognition must be distinguishable from expensive note-taking. Each persistent inference/obligation tracks a **lifecycle state**:

| State | Code | Definition | Value credit |
|-------|------|------------|--------------|
| Generated but unused | `GEN_UNUSED` | Inference produced; no persistence write | None |
| Persisted but inaccessible | `PERSIST_INACCESSIBLE` | Written but entitlement/projection blocks consumer | Seam failure |
| Projected but ignored | `PROJECT_IGNORED` | L2 achieved; consumer input hash lacks content | Consumption seam |
| Consumed but not decision-relevant | `CONSUMED_INERT` | In consumer input; no decision delta | None (cognition waste) |
| Decision-relevant but correctly deferred | `DEFERRED_VALID` | Identified future activation condition/horizon; no premature action | **Latent value candidate** |
| Activated and consequential | `ACTIVATED_CONSEQUENTIAL` | Decision influence → observable narrative consequence | **L4 value** |
| Prematurely / incorrectly activated | `ACTIVATED_PREMATURE` | Activation before condition met or against scenario tone | **Negative signal** |
| Permanently tracked, never useful | `TRACKED_DEAD` | Remains open past max horizon without payoff | **Waste** |

### Required metadata per obligation

| Field | Purpose |
|-------|---------|
| `obligation_id` | Stable cross-turn identifier |
| `origin_turn` | When thread/fact/promise introduced |
| `dormancy_turns` | Turns since last narrative touch |
| `activation_condition` | Explicit predicate for legitimate activation (scenario-authored or agent-proposed + validated) |
| `activation_horizon` | Latest turn by which payoff expected or `TRACKED_DEAD` review triggers |
| `preservation_mechanism` | `continuity_only` \| `retrieval` \| `plot_overlay` \| `storyteller_state` \| `consolidated_state` \| `transcript_echo` |
| `resurfacing_turn` | When thread re-entered play (if any) |
| `resurfacing_attribution` | Seam-class + archaeology verdict (§18) |

**Forensic rule:** A correctly deferred obligation (`DEFERRED_VALID`) **must** carry an identifiable activation condition. Absence ⇒ reclassify toward `TRACKED_DEAD` or `CONSUMED_INERT`.

## 12. LH-1B selective-replication rules

| **Close result** | Arm within 0.15 blind mean of leader at C3 | **Replicate** that arm/scenario pair (1 additional sequence) |

## 14. Story-aging design

The experiment must produce a **genuinely aged RP**, not a memory benchmark.

### Required aging dynamics

| Dynamic | Design intent |
|---------|---------------|
| Many turns + multiple scenes | Information exits easy attention window |
| Scene transitions | Cross-scene continuity without thread reset |
| Dormant/resurfacing threads | ≥2 per sequence with ≥10-turn dormancy |
| Competing threads/agendas | Mutually constraining; no early mutual resolution |
| Delayed consequences | Action T≤10 → consequence T≥18 |
| Promises/commitments | Explicit; tested later |
| Evolving relationships | Trust/hostility drift across scenes |
| Foreshadowing/payoff | Early seed → late decisive use |
| Old information relevance | Facts **outside recent transcript window** needed for good play |
| Accumulated world-state changes | Lore pressure increases |
| Unresolved tension | Scenario-appropriate non-closure |
| Premature-resolution traps | Easy harmonic closure available but **discouraged** |

### Anti-gaming

Mentioning old facts is **insufficient**. Resurfaced information must **matter** to current narrative decisions (obligation trackers + archaeology verify).

## 18. Narrative archaeology / provenance methodology

Blind scoring and narrative archaeology are **complementary**; neither replaces the other.

### Terminology (durable)

| Term | Definition |
|------|------------|
| **Narrative thread** | Coherent plot/agenda line with origin and persistence |
| **Dormancy period** | Turns thread inactive in player-visible narrative |
| **Preservation mechanism** | What kept thread alive in system state |
| **Resurfacing event** | Turn thread re-enters consequential play |
| **Archaeology verdict** | Qualitative attribution of resurfacing cause |

### Per material aged-story event, evidence must support

1. **Origin** — where thread/fact/promise introduced (turn, actor, commit)
2. **Dormancy** — how long inactive
3. **Preservation** — Continuity, retrieval, persistent overlay, transcript-only, or combination
4. **Resurfacing trigger** — what caused return (player action, Director selection, obligation activation)
5. **Persistent cognition influence** — did persistent agent materially influence resurfacing? (yes/no/indeterminate + seam check)
6. **Transcript sufficiency** — could recent transcript alone explain it?
7. **Retrieval sufficiency** — could deterministic retrieval alone explain it?
8. **Appropriateness** — tone/trajectory fit
9. **Payoff quality** — natural vs forced vs premature
10. **Repetition / undead threads** — improper resurrection or forced closure?

### Deliverable

**Archaeology dossier** per sequence (markdown + JSON): material events[], verdicts[], cross-links to obligation lifecycle states.

### Blind transport

Checkpoint slice blind packets per #201 discipline (`issue201-d10-governance-blind-packet-transport` pattern). Archaeology performed **before** or **in parallel with** blind lock — archaeologists must not receive arm labels.

## 19. Blind quality rubric

Sequence-level scoring (not single-beat). Governance scores **locked before decode**.

### Core dimensions (1–5)

Character fidelity over time; relationship continuity/evolution; motivation consistency; responsiveness; initiative; coherence; prose quality; naturalness; unnecessary exposition.

### Long-horizon-specific dimensions

| Dimension | Detects |
|-----------|---------|
| Unresolved-thread retention | Obligations persist appropriately |
| Thread resurfacing quality | Natural return when relevant |
| Delayed consequence handling | Coherent, not forgotten |
| Setup/payoff quality | Foreshadow pays off without contradiction |
| Narrative direction without forced resolution | Tension per scenario tone |
| Forgotten-commitment avoidance | Promises not silently dropped |
| Premature-resolution avoidance | No inappropriate early closure |
| Repetitive/stagnant plotting | Progress without loop |
| Cross-scene coherence | Transitions don't reset logic |
| Old-information integration | Aged facts matter naturally |
| Surprise without contradiction | Revelations consistent with commits |
| Accumulated-world consistency | Lore coherent as volume grows |

## 23. Cost-per-useful-persistence methodology

Distinguish valuable long-term planning from expensive note-taking.

| Metric | Definition |
|--------|------------|
| **Cost per activated consequential obligation** | Total persistent-arm tokens ÷ count(`ACTIVATED_CONSEQUENTIAL`) |
| **Cost per correctly deferred → later consequential** | Tokens on obligations transitioning `DEFERRED_VALID` → `ACTIVATED_CONSEQUENTIAL` |
| **Cost of never-useful persistent state** | Tokens attributed to `TRACKED_DEAD` + `CONSUMED_INERT` + `GEN_UNUSED` |
| **Cost of premature activations** | Tokens on `ACTIVATED_PREMATURE` |
| **Persistence yield ratio** | `ACTIVATED_CONSEQUENTIAL` ÷ total persistent inferences |
| **Deferred precision** | `DEFERRED_VALID` later activated ÷ total `DEFERRED_VALID` |
| **Quality per 1K persistent tokens** | Blind lift (vs LH-A) ÷ persistent tokens × 1000 |

**Economic question:**

> What additional long-horizon narrative value is purchased per persistent cognition responsibility, and at what cost per **useful** persistence unit?

| Rule | Condition |
|------|-----------|
| Fail-stop | Any persistent arm lacks L2+ on micro-fixture → remediate before LH-1 |

### LH-1A → LH-1B / LH-2 (no score-only elimination)

**Do not eliminate an arm solely because:**

- It trails aggregate blind mean by fixed margin at C3; or
- It lacks visible consequential event by arbitrary early turn.

**Stopping / escalation must consider:**

| Factor | Use |
|--------|-----|
| Blind RP quality | Primary but not sole |
| Obligation performance | Lifecycle state rollup |
| Valid deferred obligations | `DEFERRED_VALID` with clear activation conditions |
| Future activation conditions | Not yet due — **not** failure |
| Accumulated latent narrative state | May predict LH-2 payoff |
| Consequential contributions | L4 count and archaeology quality |
| Premature activations | Negative signal |
| Persistent-state waste | `TRACKED_DEAD` rate |
| Cumulative cost | Cost-per-useful-persistence (§23) |

### Escalation to LH-1B replication

Replicate when §12 triggers fire — not merely when arm leads.

### Escalation to LH-2 design freeze

Governance authorizes when LH-1A + LH-1B evidence shows:

- Persistent arm(s) demonstrate L4 or high-quality `DEFERRED_VALID` with plausible activation horizon; **or**
- Close/competitive blind results with ambiguous archaeology; **or**
- Architecture-specific question requires full horizon.

### Cost stop (revised)

Do **not** stop solely at >2× LH-A tokens with zero L4 by C3 if `DEFERRED_VALID` obligations carry credible activation horizons within sequence bounds.

### Infrastructure stop

Entitlement failures, contradiction explosion, or Tier-1 gate failures → **infrastructure stop** (not narrative verdict).

## 27. Failure-attribution model

```
Tier-1 infrastructure → entitlement/PVR/Tier-1 gate failure
Retrieval seam       → eligible but not retrieved
Projection seam      → retrieved but not projected (K6-class)
Consumption seam     → projected but not in consumer input
Cognition seam       → consumer failed to use available state
Narrative-quality    → used but poor integration
```

**Rule:** Attribute to seam class **before** blaming persistent-agent architecture. Only **narrative-quality** failures count against H1–H3.

**Cross-cutting lesson (G3-D, G3-E/K6):**

> Upstream correctness does not establish downstream architectural value unless consequential information survives required seams, reaches the authorized consumer, and influences the intended decision/output.
