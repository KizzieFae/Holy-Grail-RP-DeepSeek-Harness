## 6. Plot/Scribe topology implication

**Supported by complete record (high confidence on removals, medium on tiering):**

- **Retain** Plot/Scribe-class **capability** (narrative planning, obligation persistence, downstream projection).
- **Default off synchronous critical path** unless obligation/complexity triggers escalation (A2 §3).
- **Do not** treat synchronous Storyteller preamble/post-commit pressure as mandatory (Package D).
- **Do not** infer R5 failure disproves Plot; infer **current always-on synchronous stack** is not justified by demonstrated marginal retention.

**Immediate-turn value:** LH-0 and G3-D traces support **same-session** communication of persisted facts when consumers project them.  
**Longitudinal value:** LH-1A supports **descriptive** narrative utility signals; **causal R5** not isolated there.  
**Cost:** LH-1B ~2.28h wall / 349 inference events for 108 turns; Package D and coverage audit document per-turn multiplication of kinds; campaign rollups often incomplete (zeros).

## 9. A2 reassessment

**A2 restatement:** Deterministic substrate + primary RP cognition (Character/Director/Narrator) + **persistent Plot/Scribe off critical path by default** + obligation-driven escalation + deterministic-first validation.

**Does evidence still support A2?** **Yes** — strengthened by LH-1B (R4 without R5 mandate for synchronous persistence) and Package D removals; **not contradicted** by aging stop (aging tested a narrow R5 claim, not Plot capability).

**Refinement:** Emphasize **logical authority boundaries** even if physical inference consolidation occurs on simple beats; tiering triggers remain **medium-confidence** design work, not blockers.

**A4 (current always-on stack):** **Not justified** as default target; retain as migration baseline only.

## 10. Complexity / latency / quality

- **Complexity:** ~26 production inference kinds (coverage audit); Package D shows many stages are removable without protected-outcome loss.  
- **Latency:** Dominant cost from stacked synchronous cognitions; D-01/D-10 show large preamble/post-commit slices removable.  
- **Quality:** Blind scores largely stable or improved on removals; G3-E modest A2 retrieval advantage on some dimensions; **not** a license to delete Plot entirely.

**Deterministic vs semantic:** Continuity/PVR/validation remain deterministic gates; semantic repair **narrow and failure-triggered**.

**Logical vs physical:** Consumers and commit authority remain logical even if implementation batches LLM calls.
